# Sample Maps

This folder contains sample maps generated by the Maidenhead Grid Square Contest Map Generator, demonstrating the tool's capabilities with real amateur radio contest data.

## K2UA Microwave Contest Maps

These maps show K2UA's contacts during microwave contests, demonstrating multi-band analysis across different frequency bands:

### 10 GHz Band Maps
- `K2UA_10 GHz_northeastern_north_america_maidenhead_map.png` - CSV format (24 grids, 30 contacts) — pre-fix, see note below
- `K2UA_10G_northeastern_north_america_maidenhead_map.png` - Cabrillo format, all operating locations combined (73 unique grids, 195 contacts)

### 24 GHz Band
- `K2UA_24G_northeastern_north_america_maidenhead_map.png` - all operating locations combined (15 unique grids, 32 contacts)

### 47 GHz Band  
- `K2UA_47G_northeastern_north_america_maidenhead_map.png` - all operating locations combined (6 unique grids, 7 contacts)

### 75 GHz Band
- `K2UA_75G_northeastern_north_america_maidenhead_map.png` - all operating locations combined (4 unique grids, 4 contacts)

### 123 GHz Band
- `K2UA_123G_northeastern_north_america_maidenhead_map.png` - all operating locations combined (2 unique grids, 4 contacts)

## Map Features Demonstrated

- **Multi-band Analysis**: Separate maps for each frequency band
- **Contact Density Visualization**: Color-coded intensity showing contacts per grid
- **4-digit Grid Labels**: Small labels at lower-left corners for reference
- **Grid Square Outlines**: Light gray 1°×2° boundaries for VHF/UHF/microwave bands
- **Regional Zoom**: Automatic focus on northeastern North America
- **Geographic Context**: Coastlines, borders, and Great Lakes for reference
- **Whole Degree Axes**: Clean longitude/latitude labels (77°W, 78°W, 42°N, 43°N)
- **Professional Appearance**: High-resolution PNG output suitable for presentations

## Data Sources

- **Cabrillo Format**: Standard amateur radio contest log format (.cbr/.log files)
- **CSV Format**: Flexible spreadsheet format with automatic column detection
- **Multi-row Headers**: Support for complex CSV formats with title rows

These samples demonstrate the tool's ability to handle both simple CSV exports and complex contest log formats while producing clear, informative visualizations for amateur radio contest analysis.

> **Note:** The five Cabrillo-format `K2UA_10G/24G/47G/75G/123G_northeastern_north_america_maidenhead_map.png`
> files above were regenerated on 2026-08-20 with the current code to fix
> the same double-counting bug described below — they now show the corrected,
> combined-across-all-locations contact counts for `logs/k2ua.log` (one map
> per band, using `--home-grid` to force single-location treatment so every
> stop's contacts appear together). The `K2UA_10 GHz_..._maidenhead_map.png`
> CSV-format file is still pre-fix and its source CSV isn't available to
> regenerate, so treat its count as unverified. See the v1.3.0 samples below
> for the corrected per-location breakdown of the same Cabrillo log.

## v1.3.0 Samples: Local Path Maps & Multi-Location Splitting

Generated with the current code (`--paths`, auto-detected continents) from two
real logs kept out of version control in `logs/` (see `.gitignore`): a
single-location 10 GHz and Up log (`K5TR-082610GHZ.CBR`) and a multi-location
rover log spanning five microwave bands (`k2ua.log`).

### K5TR — single operating location, 10G band
- `K5TR_10G_central_north_america_maidenhead_map.png` — contact-density map, 13 unique grids / 13 contacts
- `K5TR_10G_EM00UF_central_north_america_grid_paths_map.png` — path map: home grid EM00UF to each of 13 worked stations, labeled with callsign and distance in km (longest 380.0 km)

A single-location log gets plain, un-suffixed filenames — no location tag needed.

### K2UA — rover log, 5 bands × up to 15 operating locations
This log reports a different home grid on many QSOs (a rover working the
contest from multiple stops), so the tool automatically generated a separate
contact-density map *and* path map for every band/location combination it
detected — 74 files total:

| Band | Locations detected |
| --- | --- |
| 10G | 15 (EN91KT, EN91OV, EN91RX, FN02EI, FN02NU, FN02OX, FN02XU, FN03WA, FN12FV, FN23HA, FN23HB, FN32JP, FN32KP, FN32OU, FN33KD) |
| 24G | 11 (EN91KT, EN91RX, FN02NU, FN02XU, FN03WA, FN12FV, FN23HB, FN32JP, FN32KP, FN32OU, FN33KD) |
| 47G | 4 (EN91KT, FN02NU, FN23HB, FN32OU) |
| 75G | 4 (EN91KT, FN02NU, FN23HB, FN32OU) |
| 123G | 2 (EN91KT, FN23HB) |

Each location's files use its home grid in the filename, e.g.
`K2UA_10G_EN91KT_northeastern_north_america_maidenhead_map.png` and
`K2UA_10G_EN91KT_northeastern_north_america_grid_paths_map.png`, so every
stop's map is self-contained and never collides with another stop's map for
the same band.

This set also shows two other v1.3.0 changes: the contact-density colorbar
now shows whole-number ticks only, and path-map distance labels are in
kilometers (matching ARRL 10 GHz and Up Contest scoring) instead of miles.

## v1.5.0 Samples: Interactive HTML Maps

`K5TR_10G_central_north_america_maidenhead_map.html` and
`K5TR_10G_EM00UF_central_north_america_grid_paths_map.html` are the `--html`
counterparts to the two K5TR PNGs above, generated with `--paths --html` from
the same log. Open either one in a browser: hover (or tap, on mobile) any
grid square or worked-station point to see a popup with that contact's
callsign, date, six-character grid, and other QSO details. They load
[Leaflet](https://leafletjs.com/) from a public CDN, so viewing them needs
internet access, same as the PNG's `--osm-basemap` does at generation time.
